# Run Replay

Trace viewer for Boyd's Grok Bot routine runs. Joins each run's tool calls, files written, and errors into one timeline so a failure can be replayed step by step.

TokenMax burn build (from the @poteto "what did you get done this week with @bot?" thread). Read-only over `/home/box/agent-data` — never writes outside this folder.

## Screens

1. **Runs** (`#runs`) — recent routine runs + pinned DEMO escape-room crash  
2. **Replay** (`#replay`) — step-through timeline with play/pause and detail pane  
3. **About** (`#about`) — source, privacy, Escape Room deferral note  

## Run

```bash
./run.sh          # build + serve http://127.0.0.1:4308/
./run.sh --shots  # + screenshots/
```

Offline single file: `dist/run-replay.html`

## Data

- Live: `automations/*/runs.json` joined to `audit.jsonl` by time window (metadata only — tool names, hosts, truncated shell verbs; no prompts or secrets)
- DEMO: `data/demo-trace.json` — labeled fictional Oct 8 Escape Room crash (does **not** modify `escape-room/`)
- Snapshot: `data/runs.json` (regenerated by `collect.py` / `build.py`)

## Layout

- `web/` — index.html, app.css, app.js  
- `collect.py` / `build.py` / `server.py` / `tests/screenshot.sh`
