What this is

        
A local trace viewer that joins each routine run’s tool calls, files written, and errors into one timeline — so a failure (like the Oct 8 Escape Room half-finish) can be replayed step by step.

        
Inspired by @EvASuKa2222’s ExecWeave agent/OS execution graph in the @poteto “what did you get done this week with @bot?” thread.

      

      

        
Data & privacy

        
    
          
  • Read-only over /home/box/agent-data (runs.json + audit.jsonl)
    • 
          
  • Metadata only: bot name, routine, tool/app names, hosts, durations
    • 
          
  • No prompts, full shell commands, secrets, or message bodies
    • 
          
  • Writes stay inside /workspace/tokenmax/run-replay/
    • 
        

      

      

        
DEMO crash

        
When live metadata is sparse, the pinned Escape Room evening push — EXAMPLE crash still shows a full failure timeline. It is labeled DEMO and does not modify escape-room/. Real Escape Room work stays deferred to Thu Oct 15.

      

      

        
Offline

        
Single-file snapshot: dist/run-replay.html. Live API (when served): /api/runs, /api/runs/<id>, /api/refresh.
